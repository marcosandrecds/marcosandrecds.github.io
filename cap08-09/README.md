## Descrição
O projeto utiliza CSS Grid para estruturar o layout principal da página, dividindo-o em três áreas nomeadas: intro, main e sidebar. A sidebar permanece fixada com position: sticky enquanto o conteúdo principal rola. Flexbox foi aplicado na coluna de artigos do conteúdo principal, no rodapé e nos blocos internos da sidebar.
A paleta de cores é composta por tons de verde-floresta escuro, dourado envelhecido e verde-vivo como acento, criando uma atmosfera noturna e refinada.

## Recursos Utilizados
- CSS Grid
- Flexbox
- Variáveis CSS
- Media Queries
- Tipografia personalizada via Google Fonts
- Efeitos :hover com transition
