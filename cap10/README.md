# Projeto — Recriação Responsiva

## Autor
Marcos André

## Site Escolhido
Twitch

## Link do Site
https://twitch.tv

## Objetivo
Recriar a homepage da Twitch, desenvolvido de forma simplificada substituindo conteúdos reais por dados genéricos.

## Estratégia Responsiva
Mobile-first utilizando Flexbox e CSS Grid.

## Breakpoints
- 600px
- 900px
- 1200px

## Recursos Utilizados
- CSS Grid
- Flexbox
- clamp()
- prefers-color-scheme
- Media Queries
- Variáveis CSS (--custom-properties)
- aspect-ratio nos cards e categorias
- position: sticky no header

## Adaptações Realizadas
A versão recriada simplifica a estrutura original da Twitch para focar nos conceitos de responsividade, substituindo elementos dinâmicos por representações estáticas e adaptando o layout de sidebar para uma navegação mais acessível em dispositivos móveis.

## Dificuldades
Adaptar a grade de categorias
Alguns problemas com a locação dos logos da twitch
