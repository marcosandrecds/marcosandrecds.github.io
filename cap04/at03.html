2. Ranking de Tecnologias

  1. Angular — Framework robusto mantido pelo Google, muito utilizado em aplicações corporativas de grande porte que exigem estrutura e organização rigorosa.

  2. Vue.js — Framework progressivo e de fácil aprendizado, ideal para quem está iniciando no desenvolvimento frontend e busca flexibilidade.

  3. JavaScript — Linguagem de programação essencial para a web, responsável por toda a interatividade e dinamismo das páginas modernas.

  4. CSS — Linguagem de estilização fundamental para definir a aparência visual das páginas web, incluindo layout, cores e tipografia.

  5. HTML — Base de toda a web, linguagem de marcação responsável pela estrutura semântica e organização do conteúdo de qualquer página.

3. Glossário Técnico

HTML
HyperText Markup Language — linguagem de marcação usada para estruturar o conteúdo de páginas web.
Padrão mantido pelo W3C e WHATWG, atualmente na versão HTML5.
CSS
Cascading Style Sheets — linguagem de estilização usada para definir a apresentação visual de documentos HTML.
Permite controlar layout, cores, fontes, animações e responsividade das páginas.
JavaScript
Linguagem de programação interpretada, orientada a objetos e baseada em eventos, usada para adicionar interatividade às páginas web.
DOM
Document Object Model — representação estruturada em árvore de um documento HTML, que pode ser manipulada via JavaScript.
API
Application Programming Interface — conjunto de definições e protocolos que permite a comunicação entre sistemas de software.
HTTPS
Protocolo de comunicação usado para transferência de dados entre cliente e servidor na web. O HTTPS é a versão segura com criptografia TLS.
URL
Uniform Resource Locator — endereço utilizado para localizar recursos na internet, como páginas, imagens e arquivos.
DNS
Domain Name System — sistema que traduz nomes de domínio legíveis por humanos (ex: www.exemplo.com) em endereços IP numéricos.
